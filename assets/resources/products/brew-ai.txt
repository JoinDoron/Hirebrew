PRACTICAL USE CASES
Write a more considerate candidate follow-up
Situation: A recruiter needs a clear next-step message but does not want a cold, generic invitation.
Workflow: Try the sample invitation, confirm the requested action and edit the tone so the candidate knows how to respond.
Intended improvement: The reviewer has a considered draft ready for the appropriate communication process, without anything being sent by this preview.

Keep an interview summary honest
Situation: A panel has useful observations and one important area it has not yet tested.
Workflow: Explore a summary that distinguishes the evidence from the gap, then edit it before discussing a follow-up with the hiring team.
Intended improvement: The open question remains visible rather than being turned into an unsupported judgement about the candidate.

Give the first week a human rhythm
Situation: A manager wants a new colleague to meet the right people and start learning without an overwhelming checklist.
Workflow: Review the sample welcome plan, adapt its sequence to the role and identify the manager's check-in point.
Intended improvement: The manager has a starting structure to discuss with the new joiner and people team.

PILOT

Start with approved, non-personal sample inputs and a named reviewer. Evaluate whether the result is accurate, appropriate and useful before considering broader access or a live action.

SCOPE BOUNDARIES
Brew examples on this website are scripted and run locally. No live model, autonomous decision, message delivery, production approval enforcement or enterprise data access is represented as deployed.

AI AND HUMAN REVIEW
The design principle is simple: suggestions should be understandable, editable and proportionate to the task. Before any live AI pilot, agree the provider, allowed inputs, data handling, review responsibilities and evaluation criteria. Do not use the public preview for candidate or employee personal information.
Example prompt: Example evaluation question: Does this fictional draft preserve the source facts, surface uncertainty and leave the consequential decision with the responsible person?
